What an embedding means
We won’t use them for Task 1 but you should know what they are for Task 2.
An embedding model transforms text into a fixed length vector using learned parameters. This model produces 384 coordinates per passage or question. These coordinates collectively represent useful relationships between texts; coordinate 17 does not have a reliable label such as “safety.” You are using a pretrained model, not training a new model on six paragraphs.
Normalize a vector by dividing it by its length. For normalized vectors, multiply matching coordinates and sum the products to obtain cosine similarity. A larger value means closer alignment in this representation. It does not mean that a passage answers the question or that its claims are true.
The embedding model finds candidate evidence. The language model writes the answer. Ordinary RAG changes the context supplied to the generator, not its learned weights.

Keep the distinction clear
The functions encode_query and encode_document distinguish the two roles. With this model they use the same underlying encoding behavior. A document is not converted into an answer, and a question is not answered by computing its vector. Answer generation comes later.
